EXECUTIVE SUMMARY

This report documents the design and development of an enterprise e-commerce and operations management platform for Polar Fiber (Addis Ababa, Ethiopia). Using TanStack Start, React 19, TypeScript, Tailwind CSS v4, and Aiven Cloud MySQL 8 with SSL encryption, the intern transformed manual, phone-based inquiry and ordering operations into a secure, automated web platform featuring real-time product catalogs, quotation intake, tamper-proof ordering, customer dashboards, and an administrative suite.

CHAPTER TWO: INTERNSHIP EXPERIENCE

Assigned to the Information System & Infrastructure section under Ato Teha Mohammed, the intern applied concepts in Web Systems, Database Normalization, and Computer Security to construct a full-stack production system with zero-trust pricing and HMAC-SHA256 session authentication.

CHAPTER THREE: SYSTEM DESIGN & IMPLEMENTATION

The platform features a Three-Tier architecture (React 19 UI, TanStack Start Server Functions, and Aiven Cloud MySQL 8), a normalized 3NF relational schema (7 tables), and cryptographic cookie authentication with role-based access control.
